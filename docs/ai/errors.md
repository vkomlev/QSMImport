# Known Issues / антипаттерны

## 1. Дубли вопросов при повторном импорте в QSM (исправлено, `e661c04`)

До коммита «Добавил защиту от дублей вопросов» повторный запуск
`import-from-gsheets` по той же таблице создавал вопросы заново вместо
обновления существующих. Исправление добавило upsert-логику в
`app/qsm/repositories.py` (~99 новых строк) и правки в `ImportService`
(`app/qsm/services.py`) — поиск существующего вопроса перед вставкой.
При изменении логики импорта в QSM проверять, что повторный запуск на тех же
данных остаётся идемпотентным (не плодит дубли квизов/вопросов).

## 2. Формат `TaskUpsertItem` для LMS менялся под требования API (`c7ed34a`)

Коммит «Оптимизирован импорт под требования API» переписал большую часть
`app/mappers/lms_task_mapper.py` (719 изменённых строк) под актуальную схему
`TaskContent`/`SolutionRules` LMS Core API. Это внешний контракт проекта LMS
(`d:\Work\LMS`) — при обновлении OpenAPI-схемы на стороне LMS маппер здесь
рассинхронизируется молча (Python не проверяет схему статически, ошибка
всплывёт только на `/api/v1/tasks/validate` или `/bulk-upsert` в виде HTTP 4xx).
Перед доверием к дампу `TaskUpsertItem` из `dry-run-lms-import` — сверять со
свежей версией контракта LMS.

## 3. Молчаливые пустые строки при несовпадении заголовков колонок Google Sheets

`app/datasources/google_sheets.py` (`_cell_str`) возвращает `""` для любого
отсутствующего ключа вместо ошибки. Переименование или опечатка в заголовке
листа («Тема» → «Название темы» и т.п.) не даёт исключения — вопросы
импортируются с пустыми полями. Диагностика: сверять фактические заголовки
листа со списком в `docs/ai/architecture.md` (`GoogleSheetsSource.fetch_rows`)
до отладки логики импорта.

## 4. `import-to-lms` без dry-run пишет боевые данные необратимо

`LmsImportService.import_from_gsheets` при `lms_import_dry_run=False` отправляет
все валидные строки одним `bulk-upsert`-запросом в LMS. Ошибки валидации по
отдельным строкам логируются и пропускаются, но не откатывают уже отправленные
задачи. Перед боевым запуском `import-to-lms` — сначала прогнать
`dry-run-lms-import --limit N` или временно выставить `LMS_IMPORT_DRY_RUN=true`.
